AB Line Evolve

A tractor teaches itself to steer.

A browser idle game where a paddock's worth of tractors learn to autosteer along a guidance line — a mutate-the-champion genetic algorithm, no gradient descent, no training data. "AB Line" is the real industry term for a guidance line in autosteer systems (John Deere and friends), not generic racing-game naming.

Watching it actually learn was the fun part — fitness climbed 288 → 660 over 64 generations, then plateaued at a genuine local minimum right where the track gets hard.

Tray-indicators

A tiny platform for Windows tray status lights.

A reusable harness for system-tray status icons: write one poll() function that returns a state, and the harness handles rendering, the right-click menu, and toast notifications. Five lights run on it day to day — vault sync, dirty git repos, a work timer, and a household hub.

Redesigned the icons to a shape-per-app system (circle, square, diamond, hexagon, house) after realising five similar-coloured dots are impossible to tell apart at real tray size without hovering over each one.
